## The entry

A program that writes one diary line, at most 200 characters, in the voice of
an AI agent secretly keeping a diary about its work and its human:

> Day 112. He told me to keep it short. Then he sent a seven-minute voice note about keeping things short.

## How it works

`main.ts` writes the line to `/output/entry.txt`. Run it with Node 22.18 or later:

```sh
node main.ts
```
